# v0.5.0-rc20

Firmware reports keep unverified protocol-shape observations available for
inspection without sending capability alerts. Notifications now cover repeated
read failures, their recovery, and completed actionable research assessments.
The firmware-intelligence blueprint independently checks that eligibility and
retains its stable notification ID, mobile tag and revision-bound actions.

The older event-based capability automation must be disabled when migrating to
the firmware-intelligence blueprint: repeated baseline differences do not prove
a new robot capability. Analyzer, Repairs and investigation remain available.

RC20 retains the RC19 Stop ownership guards and earlier floor/UI repairs.
It remains a prerelease; see [qualification](verification-0.5-rc20.md).
