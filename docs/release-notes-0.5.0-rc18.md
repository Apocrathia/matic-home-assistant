# v0.5.0-rc18

The plan picker now says **1 room** for a one-room saved plan. A dedicated
singular translation preserves localization; other room counts retain their
existing translated wording.

This candidate carries the RC17 floor-authority, native-room identity,
restart-recovery and rendering repairs. It changes the plan-card wording and
release metadata; robot execution code is unchanged.

RC18 remains a prerelease. Required review/CI, HACS installation, candidate
readback and the remaining runtime, device, physical/cadence and owner gates
apply before stable publication. See the [acceptance matrix](acceptance-0.5.md)
and [current qualification](verification-0.5-rc18.md) for scope and limits.
