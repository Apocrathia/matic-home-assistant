# v0.5.0-rc33

New plans and custom areas appear on Home by default. Each user's existing
shortcut choices stay intact, including items they have hidden. The small icon
at the trailing edge of **Shortcuts** opens ordering controls; move an item up
or down and choose **Done**. Reordering does not start a cleaning run.

Compatible saved areas can acquire missing room-boundary snapshots when their
original room shape and position are still exactly provable. This keeps a later
harmless map refinement from requiring an avoidable confirmation. Ambiguous or
changed cleaning locations continue to require review; missing historical map
geometry is not guessed.

This candidate includes the current 0.5 Stop, room-color and connection recovery
changes. Source review, CI, installed runtime, devices and supervised robot
acceptance remain separate qualification steps.
